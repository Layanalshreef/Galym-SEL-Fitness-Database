# Galym SEL Fitness Database

## Overview

Galym SEL Fitness is a database management project designed for a fitness center. The system manages trainees, staff, memberships, and related operations using relational database concepts and SQL.

## Features

- ER Diagram
- Relational Schema Design
- SQL Table Creation
- Constraints
- SELECT Queries
- Aggregate Functions
- Joins
- Subqueries
- Views

## Technologies Used

- SQL
- Database Design
- ER Modeling
- Relational Schema
